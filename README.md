Bonjour, se projet a pour but d'apprendre le python
ainsi que d'ameliorer ma logique algorithmique.

C'est un outil de conversion de base 2 , 10 et 16.
(j'ai toujours eu beaucoup de mal avec les conversion mais cree
un outil pour les faire est bien plus simple pour moi)

Je tiens a m'excuser pour les fautes d'orthographe.

L'utilisaion est simple, le programme vous demande de choisir une base de depart (le nombre que vous avez).
Ensuite cela va vous donner se meme nombre mais dans les deux autres bases. 

ex :

input
    10 base 10

output
    base 2 : 1010
    base 16 : A
